# Commit/push authorization (Nathan, 2026-09-26)

This repo works through PR branches, not direct commits to `main`: commit
and push freely to the active PR branch — no need to wait for a separate
"commit and push" confirmation once a change is ready.

Nathan reviews the raw PR diff on GitHub before merging. Never merge a PR
without his explicit OK — pushing to the branch is not the same as
approval to merge.
